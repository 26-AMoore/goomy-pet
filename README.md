## Run
### Linux / MacOS
Have [zig](https://ziglang.org/) installed
```bash
git clone http://github.com/26-amoore/goomy-pet
cd goomy-pet
zig fetch --save git+https://github.com/raylib-zig/raylib-zig#devel
zig build
./zig-out/bin/goomy
```
